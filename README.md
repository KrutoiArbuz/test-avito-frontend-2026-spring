# AI-ассистент для улучшения объявлений (Авито)

Веб-приложение — личный кабинет продавца с интегрированным AI-ассистентом для анализа карточек товаров и генерации рекомендаций по улучшению текста.

## Запуск

1. Настройка и запуск Backend (Сервер)

```sh
cd server
npm install
npm start
```

Сервер будет доступен по адресу http://localhost:8080.

2. Настройка и запуск Frontend (Клиент)

В новой вкладке терминала:

```sh
cd client
npm install
npm run dev
```

Клиент будет доступен по адресу http://localhost:5173.

## Стек

- React 19.2.4 (Vite)
- TypeScript
- Material-UI (MUI)
- React Router v6
