# AI-ассистент для улучшения объявлений (Авито)

Личный кабинет продавца с интегрированным AI-ассистентом.
Приложение позволяет пользователям просматривать свои объявления, редактировать их и получать рекомендации по улучшению текста от нейросети. Интерфейс включает в себя удобную навигацию и наглядную обработку ошибок.

## Функционал

- Просмотр списка объявлений с поддержкой пагинации.
- Поиск и фильтрация (все параметры сохраняются в адресной строке).
- Просмотр детальной информации об объявлении с каруселью изображений.
- Редактирование карточки товара с автосохранением черновика.
- AI-генерация описания и оценка рыночной стоимости.
- Валидация форм и отображение ошибок.

## Запуск

Проект можно запустить локально или через Docker.

### Вариант 1: Локальный запуск

Убедитесь, что у вас установлены Node.js (v20+) и Ollama.

**1. Запуск Ollama**
Скачайте модель и запустите сервер (в отдельном терминале):
```bash
ollama pull llama3
ollama serve
```

**2. Запуск бэкенда**
```bash
cd backend
npm install
npm start
```

**3. Запуск фронтенда**
```bash
cd frontend
npm install
npm run dev
```

### Вариант 2: Docker Compose

Docker Compose автоматически запускает все сервисы. Убедитесь, что установлен Docker.

**1. Запуск контейнеров:**
```bash
docker-compose up
```

**2. Загрузка модели Ollama (один раз):**
```bash
docker-compose exec ollama ollama pull llama3
```

Доступ к приложению: http://localhost:5173

## Технические особенности

- **Синхронизация с URL:** Параметры поиска, фильтрации и сортировки привязаны к Query Params в URL. Это позволяет копировать ссылку и делиться конкретными результатами поиска.
- **Сохранение черновиков:** Введенные данные на странице редактирования сохраняются в `localStorage`. Если случайно закрыть или обновить страницу, прогресс не потеряется.
- **Интеграция с локальной LLM:** Все запросы к нейросети выполняются локально через Ollama, что обеспечивает безопасность данных и бесплатное использование.
- **Строгая валидация:** Для проверки данных в формах используется библиотека Zod.

## Тестирование

Интерфейс отзывчив и корректно работает как на десктопе, так и на мобильных устройствах. 
Для проверки надежности базовых элементов UI настроен Vitest. Все "глупые" (презентационные) компоненты покрыты юнит-тестами.
